# Predicting Student Exam Scores
 
**Kaggle Playground Series · Regression**
 
Predicting a student's exam score, from 0 to 100, from things like study hours, class attendance, sleep, study method and exam difficulty. The data is synthetic, generated by Kaggle, with 630,000 students to learn from and 270,000 to predict.
 
---
 
## 🎯 Result
 
A blend of three tuned models reaches a typical error of about **8.5 points** on the validation data (RMSE 8.47). The final blend uses LightGBM (65%) and XGBoost (35%). CatBoost was tested but added nothing to the mix.
 
---
 
## 🛠️ How it was built
 
1. **Tuning** LightGBM, XGBoost and CatBoost separately with Optuna.
2. **Blending** them with weights chosen to minimise the error, then generating the submission.
3. **A cleaner version in progress:** one feature function applied the same way to training and test data, data-driven bins, 5-fold cross-validation and blend weights optimised on out-of-fold predictions. It fixes issues found in the first version, such as tuning on data that was missing the engineered features.
